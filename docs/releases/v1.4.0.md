# v1.4.0 — Android 网络检测 & 斗地主重写 & 国际化收官

## 中文

### 斗地主完全重写

- **叫抢模式**：新增"叫地主→抢地主"流程，无人抢时自动确认
- **叫分模式**：保留原 1-3 分叫地主
- **多局制**：总局数可选 3/6/9/12 局，累计比分，局末投票续赛（+3 局）
- **出牌计时器**：服务端 `scheduleTurnTimer`，超时自动 PASS
- **提示功能**：`generateHints` 覆盖单张/对子/三张/顺子/连对/飞机/炸弹/火箭，仅压牌阶段显示，点击循环
- **AI 适配**：叫抢/续赛投票/局末全部适配走 `getCurrentActor` hook
- **设置 UI**：房间内可配 4 组规则 + 时长 + 总局数
- **15 个新测试**，全过（106/106）

### Android 增强

- **旋转不重启**：`AndroidManifest.xml` 的 `configChanges` 扩展 11 个属性，杜绝旋转导致 Activity 重建
- **移动数据检测**：`ConnectivityManager` 自动识别 WiFi / 以太网 vs 流量。流量下设置 `?wifi=0`，WebView 隐藏联机面板、显示离线横幅、过滤仅 AI 游戏、阻止扫码/输入房号加入
- **网络变化监听**：`registerDefaultNetworkCallback` 实时检测 WiFi ↔ 流量切换，自动刷新页面
- **状态栏双语**：弃用 Android `strings.xml`（仅匹配系统语言），改为 `evaluateJavascript` 读取 WebView `localStorage` 语言，支持页面内中英文切换

### 国际化收官（Phase 4）

- **全部 29 款游戏** `handleMove` 错误字符串替换为 `lang/` i18n key（battleship/drawguess/flightchess/liarsbar/rummikub/suikabattle/twentyfour/uno 等）
- **叙事双语化**：飞行棋 `lastMoveResult`（起飞/踩人/反弹/跳格/保底）、骗子酒馆 `roundMessage`（开枪/质疑）全部 `pick(state, zh, en)`
- **真心话大冒险双语卡牌**：4 套牌库（破冰/聚会/深度/挑战）每张卡存 `{text, textEn}`，渲染器按观看者语言渲染
- **`games/lib/i18n.js`** — `pick()` 工具函数
- **CI 修正**：`android-apk.yml` / `release.yml` 加入 `cp -r lang`，防止 APK 缺失 `lang/`

### Bug 修复

- **UNO bot**：`scoreCard()` 缺 `state` 参数 → ReferenceError → bot 无限重试循环
- **爆炸猫**：预言之牌 `.ek-fcard` 尺寸 52×70px + icon+name 双层，`.ekv`/`.ekl` 手牌布局修正
- **Canvas 棋盘缩放**：中国象棋/国际象棋/跳棋/围棋 resize 监听器调用 `render()`，F12 后棋盘不消失
- **飞行棋/德州 `next_round`**：之前用 `broadcastRoom` 全状态广播，让德州对手看到上一轮底牌；现在统一走 `broadcastGameView`

## English

### Doudizhu rewrite

- **Call/Rob mode**: new "call landlord → rob landlord" flow with auto-finalize
- **Score-bid mode**: preserved original 1-3 scoring auction
- **Multi-round**: 3/6/9/12 configurable rounds, cumulative scoring, continue vote (+3 rounds)
- **Play timer**: server-side `scheduleTurnTimer`, auto-pass on timeout
- **Hint system**: `generateHints` covers singles/pairs/triples/straights/consecutive pairs/planes/bombs/rockets; shown only when beating opponent; cycles on click
- **AI support**: rob/continue_vote/roundEnd phases wired through `getCurrentActor` hook
- **Settings UI**: 4 rule groups + duration + total rounds configurable in-room
- **15 new tests**, all passing (106/106)

### Android enhancements

- **Rotation fix**: `configChanges` expanded to 11 attributes, preventing Activity recreation on rotation
- **Mobile data detection**: `ConnectivityManager` detects WiFi/Ethernet vs cellular. Sets `?wifi=0` flag, WebView hides multiplayer UI, shows offline banner, filters AI-only games, blocks QR/room-code joining
- **Network change listener**: `registerDefaultNetworkCallback` detects WiFi↔data switch, reloads page automatically
- **Bilingual status bar**: moved from Android `strings.xml` (system-locale only) to `evaluateJavascript` reading WebView `localStorage` language — respects in-page zh/EN toggle

### i18n final phase

- **All 29 games**: `handleMove` error strings replaced with `lang/` i18n keys (battleship/drawguess/flightchess/liarsbar/rummikub/suikabattle/twentyfour/uno etc.)
- **Narrative bilingual**: flightchess `lastMoveResult` (launch/catch/bounce/jump/pity), liarsbar `roundMessage` (shoot/challenge) all use `pick(state, zh, en)`
- **Truth or Dare bilingual cards**: all 4 decks (icebreaker/party/deep/challenge) store `{text, textEn}`; renderer picks by viewer language
- **`games/lib/i18n.js`** — `pick()` utility function
- **CI fix**: `android-apk.yml` / `release.yml` now `cp -r lang`, preventing missing `lang/` in APK bundle

### Bug fixes

- **UNO bot**: `scoreCard()` missing `state` param → ReferenceError → infinite bot retry loop
- **Exploding Kittens**: prophecy card `.ek-fcard` sized 52×70px with icon+name dual layers, `.ekv`/`.ekl` hand layout corrected
- **Canvas resize**: chess/chinesechess/checkers/go9 resize handler calls `render()` — board survives F12 devtools
- **Flightchess/Texas `next_round`**: previously used `broadcastRoom` (full state), leaking hole cards across rounds; now routed through `broadcastGameView`
